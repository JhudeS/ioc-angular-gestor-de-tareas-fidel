# Nom de l'aplicació
gestor de tareas 
## Autor/a
Fidel ELvira      
## Descripció
Serà una aplicació per afegir tasques, organitzar-les i resoldre-les.
## Versions utilitzades
- Node.js 26.3.1
- npm 11.16.0
- Angular CLI 22.2.2
- Angular 22.2
- Git 2.54.0
## Com crear i executar el projecte
Creació:
ng new ioc-angular-gestor-de-tareas-fidel --routing --style=scss --ssr=false --standalone --file-name-style-guide=2016 --skip-git --package-manager=npm

Instal·lació i execució:
npm install
ng serve
Obre http://localhost:4200
